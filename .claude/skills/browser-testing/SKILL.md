# Browser Testing

Use Playwright MCP as the primary browser automation tool.

1. Verify MCP connectivity.
2. Navigate to the target webpage.
3. Inspect accessibility snapshots.
4. Test interactive elements.
5. Inspect console and network errors.
6. Capture screenshots for failures.
7. Produce a structured test report.

Do not use CDPSession as an automatic fallback.
